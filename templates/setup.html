Host QuestPing yourself

QuestPing is open source. This is what your own copy needs from the Discord Developer Portal.

  1. Create an application. Open the Developer Portal, choose New Application, then copy the Application ID and the Client Secret from the OAuth2 page.
  2. Add the redirect. On the OAuth2 page, add this redirect exactly: {{ redirect_uri }}
  3. Create the bot. On the Bot page, reset and copy the token. It goes in the DISCORD_TOKEN variable on your host and never into this site. Leave every privileged intent off.
  4. Invite the bot. Use this link to add it to a server, or use Add to server on the dashboard.
  5. Add a Meta token. The checker needs one to read build data. Put it in META_ACCESS_TOKEN. The README explains where it comes from and the risks.
  6. Log in. The dashboard lists every server where you have Manage Server and shows which ones already have the bot.
